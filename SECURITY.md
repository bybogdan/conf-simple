# Security policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue, discussion,
or pull request.

On GitHub, open the repository's **Security** tab and use **Report a
vulnerability** if that option is available. If private vulnerability reporting
is not available, contact the maintainer through the
[Bogdan Varlamov GitHub profile](https://github.com/bybogdan) to arrange a
private reporting channel. Do not include sensitive technical details in the
initial public contact.

Include the affected version, impact, reproduction steps, and any suggested
mitigation when it is safe to do so. The maintainer will acknowledge the report
and coordinate validation, remediation, and disclosure. Response times are not
currently guaranteed.

## Supported versions

Conf Simple is an early-stage project. Security fixes are provided for the most
recent released version. Users should back up their complete data directory and
upgrade to the latest release after reviewing its release notes.
