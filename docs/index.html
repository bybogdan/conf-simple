Your team's wiki.

A focused place for team documentation, without another stack to maintain. Pagecairn runs as one application container and keeps everything in one persistent volume.

  • One container
  • One persistent volume
  • No required external services

Simple by default

One command.
Nothing else to operate.

From the Pagecairn directory, Docker starts the application. SQLite stores the pages, local storage keeps uploads, and the persistent volume contains everything you need to back up.

No Redis. No PostgreSQL. No object storage. No queue.

terminal docker 
$ docker compose up -d --build
